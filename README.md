Умная поливалка для домашних растений с управлением через телеграмм бота.

Есть возможность поливать, включать увлажнитель, контроль наличия воды в баке.

Есть возможность задавать ночной режим, в котором не будет происходить включение реле.
Есть возможность контроля в автоматическом режиме, система сама будет решать когда включать полив и увлажнитель.
